# 🧮 Calculator Console App

A feature-rich C# console application that performs both basic and advanced calculator operations. Designed to simulate the behavior of a scientific calculator in a command-line environment.

---

## 🎯 Project Purpose

This project is developed to perform essential arithmetic operations as well as advanced mathematical functions such as power, percentage, square root, and factorial. It serves as a learning tool for mastering C# console applications and basic algorithm implementation.

---

## ✨ Key Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🧠 Power (Exponentiation)  
- 🎯 Percentage Calculation  
- √ Square Root  
- ❗ Factorial

---
